A program that draws Wednesday 18 November 2026's world news as one newspaper front page: Trump lands in Manila for Quad talks, Ukraine hits the Crimea bridge again, Iran's drone attack on a US radar in Bahrain, Canada and China extend trade deals, Britain sanctions Israeli settlement firms, Cyclone Akvan bears down on the Bay of Bengal, and Dhoni ends his IPL playing career. Pure Python 3 standard library, no network at run time — the news is baked in as data and rendered with a hand-built 5x7 bitmap font and a tiny PNG encoder.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png` (1024x1024, about 20 KB). Run it twice and the bytes are identical.
